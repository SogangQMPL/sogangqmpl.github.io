공용 GitHub 계정 SogangQMPL의 로그인 방법은 이 문서와 별도로 전달합니다.
새 담당자는 자신의 Codex에 로그인하고, 작업용 빈 폴더를 연 뒤 아래 첫 요청을 붙여 넣습니다.
새 PC의 브라우저에는 홈페이지 운영에 사용하는 공용 Google 계정만 로그인되어 있는 것을 기본 전제로 합니다.

========== 처음 한 번: 작업 준비 ==========

이 컴퓨터에서 서강대 QMPL 홈페이지를 수정하고 게시할 수 있게 준비해줘.

저장소: https://github.com/SogangQMPL/sogangqmpl.github.io
공개 사이트: https://sogangqmpl.github.io/
게시용 GitHub 계정: SogangQMPL

현재 작업 폴더를 확인하고, 기존 복제본이 있으면 재사용해줘. 없으면 이 작업 폴더 안에 저장소를 복제해줘.
복제한 저장소의 AGENTS.md, README.md, 관리안내.md를 읽고 기존 사이트 구조를 파악해줘.
Git과 Node.js 22 이상이 있는지 확인하고, 없으면 필요한 설치 단계만 안내해줘.
브라우저에는 공용 Google 계정만 로그인되어 있고, GitHub와 Git 명령줄에는 아직 로그인하지 않았다고 가정해줘. 게시 준비는 가능한 부분을 자동으로 진행해줘.
1. Codex의 브라우저 연결을 확인하고, GitHub가 이미 SogangQMPL로 로그인되어 있으면 그 세션을 재사용해줘.
2. GitHub에 로그인되지 않았다면 GitHub의 일반 로그인 화면에서 Continue with Google을 선택하고, 이미 로그인된 공용 Google 계정으로 진행해줘. 구글 계정과 기존 SogangQMPL 계정이 연결되어 있어야 이 경로로 로그인할 수 있어.
3. 로그인 결과가 SogangQMPL인지와 이 저장소의 수정 권한을 확인한 뒤 GitHub 웹 업로드·커밋 방식으로 게시할 수 있게 준비해줘. 공개 저장소를 읽을 수 있다는 것만으로 수정 권한이 있다고 판단하지 마. 웹 게시 경로에는 별도 Git 명령줄 인증 설정이 필요하지 않아. 이미 사용 가능한 Git 게시 인증이 있으면 계정과 권한을 확인하고 재사용해도 돼.
4. 추가 인증, 최초 계정 연결, 여러 구글 계정 중 공용 계정 확인, 필요한 브라우저 연결 단계가 나오면 내가 해야 할 정확한 화면과 단계만 안내해줘. 새 GitHub 계정을 자동 생성하거나 계정 보안 설정·새 앱 권한을 임의로 바꾸지 마.
브라우저 로그인 정보를 추출해서 Git 인증 파일로 만들거나 전달하지 말고, 실제로 사용 가능한 게시 경로가 무엇인지 알려줘.
사이트 검사와 빌드를 실행하고 PC·모바일 미리보기를 열어줘.
처음 준비하는 단계이므로 아직 공개 사이트의 내용은 바꾸지 말고, 준비된 프로젝트 폴더와 이후 작업 방법을 알려줘.

========== 이후: 수정부터 게시까지 ==========

이 저장소의 AGENTS.md를 읽고 최신 게시 내용을 확인한 뒤 아래 변경을 적용해줘.

수정 내용:
[여기에 바꿀 내용과 사진·논문 등의 자료를 적거나 첨부]

기존 디자인과 나머지 내용을 유지하면서 수정하고, PC·모바일 화면을 확인해줘.
검사와 빌드가 통과하면 기존 Git 인증 또는 로그인된 GitHub 웹 화면을 통해 반영하고 공개 홈페이지 게시까지 완료해줘. 웹 게시에는 Codex의 브라우저 연결 기능이 필요해.
GitHub Actions 배포 성공과 실제 공개 페이지까지 확인한 뒤 수정 결과와 사이트 링크를 알려줘.
별도 호스팅된 화면 편집기의 코드·스타일에도 영향이 있으면, 동기화가 필요한지와 해당 호스팅 권한이 있는지도 확인해줘.

========== 미리보기만 원할 때 ==========

[수정 내용]을 적용하고 PC·모바일 미리보기를 보여줘. 아직 GitHub나 공개 홈페이지에는 게시하지 마.

========== 참고 ==========

이전 Codex 대화나 개인 인증 파일을 전달할 필요는 없습니다.
홈페이지 소스와 작업 규칙은 저장소에서 받습니다. 자신의 Codex에 로그인하고, 브라우저의 공용 Google 로그인에서 기존 GitHub 계정으로 연결하는 과정을 Codex에 맡깁니다. Google 로그인과 GitHub 로그인, Git 명령줄 인증은 서로 다른 상태입니다. 추가 인증·최초 계정 연결·브라우저 연결이 필요한 단계만 직접 완료합니다.
main 브랜치에 변경이 반영되면 GitHub Actions의 Publish lab website가 홈페이지를 배포합니다.
화면 편집기 서버 자체를 바꾸거나 그 운영까지 넘길 때는 별도 호스팅 권한과 qmp-editor-host 소스가 추가로 필요합니다.
