GitHub 연결

세 단계로 수정하기

  1. 화면에서 선택

    수정할 페이지를 고른 뒤 글이나 사진을 누르세요.

  2. 수정하고 확인

    오른쪽에서 글을 고치거나 사진을 올리세요. 미리보기와 모바일 화면도 확인하세요.

  3. 게시하기

    GitHub를 연결하고 게시하기를 누르면 홈페이지에 반영됩니다. 배포가 끝나면 완료 표시가 나옵니다.

편집 초안은 이 브라우저에 저장됩니다. 다른 사람에게 보이게 하려면 게시하기를 눌러 주세요.
