# 디자인 수정 기록

## Research 대표 그림을 지정한 원본으로 교체 · 2026-11-02

- 첨부 스크린샷 대신 Wix 원본 파일을 사용했습니다. SPDC 광자쌍, moiré 격자, interlayer 게이트 구조는 원본 해상도로 크롭하고 2D 소자는 원본 전체를 표시합니다.
- 대표 그림은 DETAIL에서 중복 제거했습니다. SPDC의 공진기와 interlayer의 포텐셜 등 선택되지 않은 패널은 따로 남겼습니다. 빈 DETAIL 그림 목록은 더 이상 기본 원본을 자동으로 다시 표시하지 않습니다.
- Quantum light sources는 실제 논문 그림 후보를 준비하며 대표 그림 자동 교체는 하지 않습니다.

## Wix 메인 랩 이름과 대표 그림 복원 · 2026-11-01

- 메인 첫 화면에 큰 랩 이름을 세 줄로 표시하고 오른쪽에 Wix 원본 구조 그림을 배치했습니다. 그 아래 모집 안내·News·Publications를 순서대로 표시합니다. 모바일에서는 랩 이름·그림·모집 안내를 세로로 배치합니다.
- 실제 Wix에서 랩 이름은 Quicksand 400 이탤릭 50px로 확인했습니다. 같은 Quicksand 파일을 로컬로 보관하고, 현재의 넓은 본문 폭에 맞춰 PC 제목을 60px로 표시합니다. 1100px 이하와 모바일은 화면 폭에 맞게 조정합니다.
- Wix의 모집 문구는 숨겨진 접근성 제목이 아닌 표시용 SVG에서 32.9055px로 확인했습니다. Lulo Clean 글꼴 선언의 unicode-range에는 한글이 없으므로 실제 한글은 시스템 sans-serif 대체 글꼴로 표시됩니다. 현재 홈은 Arial·Malgun Gothic 계열의 굵은 33px(모바일 26px) 글자로 표시합니다.
- 연구 그림은 기존 `assets/lab-overview.webp`를 재사용하고, Wix에서 확인한 SVG duotone 색상 행렬과 부드러운 가장자리 효과를 적용합니다. 원본 PNG와 Quicksand OFL 라이선스를 보관합니다. 상세 출처는 `docs/Home-Wix-assets.json`에 기록합니다.
- 첫 화면의 이름·그림은 편집기에서 수정할 수 있습니다. 기존 News·논문·푸터·공통 좌우 여백은 유지합니다.

## 현재 검증 상태

현재 공개 페이지는 목록·소개 8개(`index`, `research`, `people`, `students`, `publications`, `news`, `activities`, `join`)와 개별 게시물 9개, 총 17개입니다. 편집기와 관리 안내 화면은 별도입니다.

현재 17개 공개 페이지를 PC 1440px와 모바일 390px·320px에서 확인했습니다. 가로 넘침과 깨진 이미지가 없으며, News·Activities에서 내부 게시물로 이동하는 것을 확인했습니다. 헤더에는 본문과 같은 글꼴과 글자 아래 여유 공간이 적용됩니다. 푸터는 PC 약 42px, 390px 모바일 약 59px입니다.

교수님 사진은 PC 160×200px, 390px 모바일 120×150px이고 학생 사진은 각각 104×130px, 88×110px입니다. 교수님 페이지에는 교수님 1명, 학생 페이지에는 학생 7명만 표시합니다.

Research의 세 분야·다섯 하위 주제와 원문 Related papers 12편 보존을 확인했습니다. 추가한 소자 논문 1편을 포함해 총 13편이 연결됩니다. SPDC에는 확인되지 않은 논문을 연결하지 않았습니다. 기존 그림 펼치기와 관련 논문 목록도 확인했습니다.

편집기에서 게시물 본문 변경 후 개별 미리보기 반영을 확인하고 검증용 수정을 되돌렸습니다. 공개 데이터에는 저장하지 않았습니다. 원문 본문 1,102문자와 사진 원본·표시판 해시를 독립 대조했고, 정적 링크·이미지 참조도 유효합니다. 소스 문법 검사, 콘텐츠 검사와 8개 페이지·9개 게시물 빌드가 통과했습니다. 최종 화면은 작업 폴더의 `preview`에 보관합니다. 원격 GitHub 게시와 실제 모바일 기기 검증은 수행하지 않았습니다.

## 이전 수정 이력

1. 초기 시안은 큰 세리프 제목·이탤릭 슬로건·녹색 로고·장식용 모아레 그림을 사용했습니다.
2. 후속 시안에서 기존 Wix 색을 되살리고 뉴스·논문과 실제 사진을 중심으로 바꿨습니다. 당시에는 뉴스 7건과 사이드바를 표시했습니다.
3. 다음 시안은 한 열로 바꾸고 Inter·Pretendard, 짧은 소개, 뉴스 3건·대표 논문 2편·사진 1장을 적용했습니다.
4. 다음 단계에서 사진·소개를 홈에서 제외하고, Wix의 헤더 배치·압축 푸터·8개 페이지·Research 계층을 적용했습니다.
5. 현재 수정본은 News·Activities 원문과 사진을 자체 게시물로 이관하고, 헤더 글꼴 통일·글자 하단 여백·인물 사진 확대를 적용합니다.

이전 6개 페이지 시안에서는 PC 1440px, 모바일 390px·320px의 가로 넘침, 메뉴·검색·필터와 편집기 로딩을 확인했습니다. 이는 해당 시점의 기록입니다. 논문 46편·구성원 8명·소식과 활동 9건은 현재 자료에서도 유지합니다.
