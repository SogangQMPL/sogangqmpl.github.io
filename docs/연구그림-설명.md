# 연구 그림의 해석과 사용

## 현재 대표 그림 · 2026-11-02

SPDC·Moiré physics·Interlayer excitons·2D semiconductor devices는 사용자가 지정한 Wix 원본 그림으로 교체했습니다. SPDC와 Interlayer는 지정 패널을 원본 픽셀로 자르고, 나머지 패널만 DETAIL에 남겼습니다. Moiré·소자 원본도 고해상도 파일로 확보했습니다. 대표 그림은 DETAIL에서 반복하지 않습니다. Quantum light sources는 실제 논문 그림 후보를 별도로 준비하며 선택 전에는 기존 간결한 도식을 표시합니다. 원본 주소·크롭 좌표·파일 해시는 `Research-대표그림-원본교체.json`에 기록합니다. 아래 내용은 원본 해석과 이전 도식 제작 기록입니다.

기준: 기존 H. Baek Research Group Wix의 Research 본문과 다섯 하위 페이지. 그림은 실제로 열어 내용과 라벨을 확인했다.

## 원래 Research 분류도

- 원문: https://baahyyjuu.wixsite.com/hyeonjun/research
- 원본 이미지: https://static.wixstatic.com/media/631814_d9dce2a0fd8e4eadb32b0ee8a83a35f5~mv2.png
- 보관 파일: `assets/research/original-overview.webp` (1500 × 844, 원래 비율 유지)

상단 **Research Materials / 2-dimensional materials**가 공통 기반이며, 아래 세 갈래로 나뉜다.

| 대주제 | 원래 그림의 항목 |
|---|---|
| Quantum information | Single photon source; spontaneous parametric down conversion (SPDC); superradiance; exciton-polariton |
| Solid-state physics | Hubbard model in moiré lattice; ferroelectricity |
| Semiconductor Devices | Field-effect transistor; neuromorphic devices; light-emitting devices; photodetector |

이것은 **공통 연구 재료 → 세 연구 방향**을 나타내는 개념 분류도이다. 나열된 기술을 모두 이미 구현한 성과로 읽으면 안 된다. 새 페이지는 같은 세 분류를 유지하고, 다섯 하위 페이지와 관련 논문을 그 아래에 연결한다.

## 새 대주제용 SVG 세 개

세 그림 모두 420 × 300 viewBox이며 흰 바탕에 기존 사이트의 남색 `#002e5d`과 보라색 `#7860bb`을 사용한다. 정량 축, 측정값, 논문 그림 번호를 넣지 않았다. 전체 분야의 모든 기술을 묘사하기보다는 두드러지는 연구 질문을 간결하게 표현했다.

| 파일 | 표현한 내용 | 권장 대체 텍스트 |
|---|---|---|
| `theme-quantum.svg` | 국소화된 2D 광원에서의 단일 광자와 SPDC의 펌프 → 광자쌍 생성 | Conceptual single-photon emitter and SPDC photon-pair generation. |
| `theme-solid-state.svg` | 회전 중첩 격자, 모아레 퍼텐셜의 국소 상태, 층이 분리된 전자·정공 쌍과 외부 전기장 | Conceptual moiré lattices and electrically tunable interlayer excitons. |
| `theme-devices.svg` | Source·Gate·Drain, 게이트 절연층과 얇은 2D 채널이 있는 트랜지스터 단면 | Conceptual gated transistor with a two-dimensional semiconductor channel. |

모두 직접 작성한 벡터 개념도이다. SVG의 `<title>`·`<desc>`에도 conceptual / not measured 또는 not experimental data를 명시했다. XML 문법 검증을 통과했다. 분야별 세 그림은 하단 Research map에서 볼 수 있다. 원본 그림들은 별도의 확대·접기 영역에서 비율을 유지해 보여주는 용도다.

## 세부 주제별 기본 schematic

다섯 기본 schematic을 현재 본문·연구 초점·DETAIL 설명과 원본 그림 11장을 기준으로 새로 그렸습니다. 흰 바탕·남색 선·분야별 파랑/청록/보라색을 사용한 SVG입니다. 폭은 600이고 세로 크기는 내용에 맞춰 720–840입니다. 하나의 장식 아이콘 대신 소재 플랫폼·작동 원리·제어 방법·응용 방향을 2–3개 구획으로 연결합니다.

| 세부 주제 | 파일 | 표현 내용 |
|---|---|---|
| Quantum light sources | `topic-quantum-light.svg` | QD·NV·2D 플랫폼, moiré·nanodot 국소화와 도파로 결합, 단일 광자 통계·간섭·얽힘·초방사, 양자 통신·컴퓨팅 |
| SPDC in 2D materials | `topic-spdc.svg` | 펌프 → signal/idler, 2차 비선형성·에너지 보존·twist 제어, 선택적 cavity와 얽힘 목표 |
| Moiré physics | `topic-moire.svg` | 격자 중첩·주기 퍼텐셜·여기자 배열, hopping t·onsite U·Bose–Hubbard, 전기장·도핑·twist 제어, 양자 시뮬레이션·강유전성 관심 분야 |
| Interlayer excitons | `topic-interlayer.svg` | 쌍극자·혼성화·사중극자·대칭 트리온, Stark 에너지/세기 제어·패턴 전극·트랩, 상호작용·polariton·비선형 응용 |

쌍극자 방향, 사중극자의 반대 쌍극자 혼성화, 트리온 전하 수, 게이트 절연층, 입사/방출 광자 방향, SPDC의 광자쌍과 얽힘의 구분을 교차 검토했습니다. 도식은 개념과 연구 방향을 표현하며 측정 그래프·정량 성능·새 실적을 만들지 않습니다. 파일·개념별 검토와 출처는 `Research-schematic-재설계.json`에 기록합니다.

PC에서는 좌측 최대 420px로 표시합니다. 1100px 이하에서는 그림과 본문을 세로 배치하며, 그림을 누르면 벡터 원본을 크게 볼 수 있습니다. 원래 3개 분야·5개 세부 주제, DETAIL 원본 그림과 관련 논문 연결은 유지합니다.
