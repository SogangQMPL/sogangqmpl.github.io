# 글꼴 출처

Inter와 Pretendard를 사이트에 포함해 사용합니다. 실행할 때 외부 글꼴 CDN에 연결하지 않습니다. 다운로드한 파일은 수정하지 않았으며, 원본 저작권·라이선스를 함께 보관합니다.

확인일: 2026-11-01

| 파일 | 용도 | 크기 |
| --- | --- | --- |
| `assets/fonts/InterVariable.woff2` | 영문·숫자, 가변 굵기 100–900 | 352,240 bytes |
| `assets/fonts/Pretendard-Regular.woff2` | 한글 본문, 굵기 400 | 765,892 bytes |
| `assets/fonts/Pretendard-SemiBold.woff2` | 한글 제목·강조, 굵기 600 | 785,856 bytes |

글꼴 합계는 1,903,988 bytes입니다. Pretendard는 필요한 두 정적 굵기의 합계가 전체 가변 글꼴(2,057,688 bytes)보다 작아 이 구성을 선택했습니다.

## 공식 출처와 라이선스

- Inter: [공식 저장소](https://github.com/rsms/inter), commit `353b61b9f4430d5f420d56605a6e7993e0941470`의 `docs/font-files/InterVariable.woff2`. [공식 라이선스](https://github.com/rsms/inter/blob/353b61b9f4430d5f420d56605a6e7993e0941470/LICENSE.txt)를 `assets/fonts/LICENSE-Inter.txt`에 보관했습니다.
- Pretendard: [공식 저장소 v1.3.9](https://github.com/orioncactus/pretendard/tree/v1.3.9), `packages/pretendard/dist/web/static/woff2/`의 Regular·SemiBold. [공식 라이선스](https://github.com/orioncactus/pretendard/blob/v1.3.9/LICENSE)를 `assets/fonts/LICENSE-Pretendard.txt`에 보관했습니다.
- 두 글꼴 모두 SIL Open Font License 1.1을 사용합니다. 저장소를 복사하거나 배포할 때 위 라이선스 파일도 함께 유지합니다.
- 정확한 다운로드 URL과 SHA-256 해시는 `assets/fonts/sources.json`에 기록했습니다.

## 로컬 CSS 정의

아래 경로는 사이트 루트의 `styles.css` 기준입니다.

```css
@font-face {
  font-family: 'Inter';
  src: url('assets/fonts/InterVariable.woff2') format('woff2');
  font-style: normal;
  font-weight: 100 900;
  font-display: swap;
}
@font-face {
  font-family: 'Pretendard';
  src: url('assets/fonts/Pretendard-Regular.woff2') format('woff2');
  font-style: normal;
  font-weight: 400;
  font-display: swap;
}
@font-face {
  font-family: 'Pretendard';
  src: url('assets/fonts/Pretendard-SemiBold.woff2') format('woff2');
  font-style: normal;
  font-weight: 600;
  font-display: swap;
}
body {
  font-family: 'Inter', 'Pretendard', system-ui, sans-serif;
}
```

한글은 400·600 굵기를 기준으로 사용합니다. 영문은 Inter 가변 글꼴이 중간 굵기를 지원합니다. `font-display: swap`으로 글꼴이 로드되기 전에도 본문을 읽을 수 있습니다. 화면 검증과 캡처는 `document.fonts.ready`가 완료된 뒤 수행하면 최종 글꼴로 확인할 수 있습니다.
